## v2에서 바뀐 것
지적해주신 대로 딥러닝 프로젝트를 손글씨(Digits)에서 **InstEval(ETH 취리히 실제 강의평가
73,421건)으로 전면 교체**했습니다. 교재 단골 데이터(붓꽃·손글씨)와 전혀 겹치지 않고,
학생 2,972명 × 교수 1,128명의 ID를 임베딩으로 학습하는 딥러닝 고유 기법이 들어가며,
사람 평가 예측이라는 난이도 높은 문제입니다.

## 프로젝트 구성
| | 데이터셋 | 결과 |
|---|---|---|
| 1. 선형회귀 | Diamonds (53,917개, 가격 예측) | R² 0.912 → 로그변환 후 0.952 |
| 2. 로지스틱 회귀 (다중 클래스) | Wine (178개, 3품종) ※과제 안내문 예시 목록에 있음 | 직접 구현 97.2% (= sklearn) |
| 3. 딥러닝 | InstEval (73,421건, 평점 1~5 예측) | 30.7% (다수결 기준선 24.0%), ±1점 정확도 68.2% |

딥러닝의 30.7%는 낮아 보이지만 이 데이터의 특성입니다 — 사람 평가는 본질적으로
노이즈가 커서 기준선(24%) 대비 개선 폭과 오류 분석이 평가 포인트이고,
보고서 3-5절(문제점)에서 이를 자세히 다뤘습니다.
